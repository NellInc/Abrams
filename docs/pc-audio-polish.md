# Accepted shell impact and engine rollback

Nell rejected the processed engine after hearing the original-game mix on
5 November 2026. The spectral reconstruction is removed from active playback.
The earlier recorded engine is restored unchanged, retaining its original
player, pitch, amplitude, gains, gates and loop bounds. Previous candidates
remain private and recoverable. This rollback is not a claim that the earlier
recording solves the unresolved engine-quality request.

The optional native `pc-restrained-polish-v1` bank now contains only
`impact.wav`, 134,400 frames (2.8 seconds), 48 kHz mono PCM16. It retains approved
Impact B with the stronger aligned explosion body. Original impact event IDs,
onsets, cadence, pool allocation, logical gain and the shared limiter are
unchanged. No extra shot or separate explosion player is created. Bluezone's
free-pack component is attributed in `NOTICE.md` and private provenance.

The loader checks the incumbent impact PCM hash, exact filename, file SHA,
format, duration and disabled looping before publishing. An invalid bank keeps
the incumbent impact. The bank cannot publish an engine, hull or debris stream.
No hull player exists. The historical supplemental bank remains recoverable,
but no debris player is allocated and neither events nor direct calls can start
it. Viewer, source clocks, mask/ownership, crew/music, world engines and saved
settings are unchanged. All licensed originals and derivatives remain private,
outside public Git, app bundles and Web exports.

Any further engine proposal must return to clean recorded source character,
with human listening before integration. Do not reuse the rejected reconstruction
or relabel numerical modulation metrics as perceptual acceptance.
